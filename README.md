# LifestealPlugin
Lifesteal SMP Plugin

Paper only 1.21 plugin!

By iusem (Arose_Editor)

🔥 Features

Lifesteal hearts system

Kill players to gain hearts

Die and lose hearts

Automatic ban at 0 hearts

Stored heart items

/withdraw hearts into items

Revive Beacon system

GUI-based revival of banned players

Full persistent storage (JSON)

Java & Bedrock compatible (Paper + Geyser)

❤️ Lifesteal Rules

Each kill gives +1 heart

Each death removes –1 heart

Max hearts = 20

Extra hearts stored as Heart items

Right-click Heart to consume

0 hearts = automatic ban

Revive Beacon revives banned players
